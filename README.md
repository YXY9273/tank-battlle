# 坦克大战 · Tank Battle

一个纯 HTML + Canvas 实现的经典坦克大战游戏，单文件、零依赖，双击 `index.html` 即可游玩。

## 玩法

- **移动**：`W` `A` `S` `D` 或方向键 `↑` `←` `↓` `→`
- **开火**：`空格`
- **暂停**：`P`
- **手机**：触屏虚拟摇杆 + 开火按钮

## 规则

- 消灭关卡内的所有敌方坦克即可过关。
- 保护基地（地图底部的红色旗帜），基地被击中游戏结束。
- 砖墙可被子弹摧毁，钢墙不可摧毁。
- 每过一关奖励 500 分，敌人数量会逐关增加。

## 技术

- 原生 HTML5 Canvas 渲染，无任何外部依赖
- 20×20 网格地图，砖墙 / 钢墙 / 基地等元素
- 简易敌人 AI（寻路 + 视野内开火）
- Web Audio 音效
- 支持键盘与触屏双输入

## 运行

直接用浏览器打开 `index.html`，或在本地启动一个静态服务器：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```
